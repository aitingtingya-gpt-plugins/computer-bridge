# Computer Bridge 0.2.5-beta

修复终端聊天的滚轮和翻页，保留双向聊天、附件及聊天内命令审批。

- 消息区滚轮直接滚动，每次移动三个屏幕行；Page Up／Page Down 按一屏翻页并保留一行重叠。
- 空行、中文、emoji、普通折行及超长单行统一按实际显示位置浏览。
- 向上翻阅停止自动跟随，回到底部恢复；新消息、历史加载、窗口缩放和审批详情变化保留阅读位置。
- 输入草稿和焦点保持，审批按钮继续支持键盘与鼠标操作。
- 复用消息与折行缓存，滚动无需重新读取服务器历史。

安装包包含服务端、Windows、Mac。升级后退出旧 TUI，重新运行 `cs` 或 `closesi`。本版的 MCP 工具和聊天协议与 0.2.5-alpha 一致。

使用说明见[双向聊天](chat.md)和[终端聊天](chat-terminal.md)。
