# Computer Bridge 0.2.5-beta

网页与终端聊天新增 Markdown 和科研公式显示，完善手机布局，并修复终端滚轮、翻页及数学渲染。保留双向聊天、附件及聊天内命令审批。

- 网页支持 Markdown、代码高亮与复制，以及 MathJax 完整数学排版；脚本、扩展和字体随产品提供。
- 终端使用二维字符显示公式，修正重音、字体作用域和上下标；表格保留多行分式、矩阵，列表和引用按可用宽度排版。
- 无法可靠显示或超出终端宽度的公式完整保留原文；使用 `/math [消息 ID]` 在本机打开完整数学排版，无需再次登录。
- 修复快速缩放和切换对话时的异步排版缓存，避免旧结果覆盖新结果；滚动与状态更新复用已完成的排版。
- 手机聊天提供“电脑与对话”抽屉，适配横竖屏、软键盘和安全区；宽公式、代码及表格可在各自区域横向滑动。

- 消息区滚轮直接滚动，每次移动三个屏幕行；Page Up／Page Down 按一屏翻页并保留一行重叠。
- 空行、中文、emoji、普通折行及超长单行统一按实际显示位置浏览。
- 向上翻阅停止自动跟随，回到底部恢复；新消息、历史加载、窗口缩放和审批详情变化保留阅读位置。
- 输入草稿和焦点保持，审批按钮继续支持键盘与鼠标操作。
- 复用消息与折行缓存，接近历史顶部时按页自动预加载更早消息，持续翻阅无需输入历史命令。

新增终端深色、浅色和高对比主题；用户和模型抬头分色，状态栏右侧固定显示“聊天ID：t1”；消息框和输入框不显示标题或附件计数。本地详细信息使用可关闭弹框，不再常驻消息末尾；发送回执自动核对。

网页与终端均可通过 `/export` 下载完整 Markdown 会话与原附件 ZIP，附件使用标准相对引用。网页的连接 ID、改名、删除改用斜杠菜单；终端增加 `/delete` 确认删除。创建新会话或模型明确关闭连接时提供连接指引。

聊天页删除重复的顶部标题和连接栏，侧栏按钮悬浮于消息区左上角。网页侧栏与终端底部显示当前电脑往返延迟，设备管理同步采用绿、黄、红分级。修复空输入回车触发的无意义终端重绘。

终端支持将拖入的图片及文件路径与说明文字一起发送为真实附件，兼容含空格的引号、转义路径及文件 URI。修复绝对路径被误认作斜杠命令，以及空输入退格和删除边界触发响铃的问题；上传失败保留未发送内容。

新增 Ctrl+Y 系统剪贴板粘贴：macOS 和 Windows 可粘贴复制的文件、截图及图片，保留当前正文，按 Enter 后发送。普通文字粘贴继续可用，剪贴板临时图片随 TUI 退出清理。

安装与更新通过 GitHub Release 提供服务端、Windows、Mac 资源。升级后退出旧 TUI，重新运行 `cs` 或 `closesi`。本版的 MCP 工具和聊天协议与 0.2.5-alpha 一致。

使用说明见[双向聊天](chat.md)和[终端聊天](chat-terminal.md)。
