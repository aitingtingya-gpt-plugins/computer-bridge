# 终端聊天

安装完成后，新开终端，在任意目录输入 `cs` 或 `closesi` 即可进入 TUI。Mac 和 Windows 使用相同命令，安装器自动配置当前用户的命令路径，无需激活 Python 虚拟环境。

Computer Bridge 的终端聊天与已经注册的本机绑定，通过同一服务器收发消息。它不会启动另一个电脑连接，也不会中断正在运行的命令。

```sh
cs
closesi
```

默认直接使用本机注册身份，显示这台电脑的对话，不打开登录网页。输入 `/resume` 打开会话名称列表，用方向键选择、Enter 打开，Esc 取消。

需要访问其他电脑时输入 `/login`，在浏览器登录账户并确认。账户模式可查看所有获授权电脑的对话，使用 `/computers` 选择新建对话所用的电脑；`/resume` 列表同时显示会话名称和电脑名称。输入 `/logout` 返回本机模式。每次重新启动 `cs` 默认进入本机模式；`cs --login` 可直接进入账户模式。

账户凭据保存在电脑配置旁的 `device-chat.json`，不保存账号密码。修改密码后需重新 `/login`。没有自动打开浏览器时，可以复制终端中的链接；`--no-browser` 只显示链接。`--config` 可指定已注册电脑的配置文件。

`cs --help` 查看参数，`cs --version` 查看当前版本；`cs --resume t1` 可直接打开已知短 ID。`closesi` 支持完全相同的参数。命令入口使用当前安装版本，更新后无需重新配置。原 `computer-bridge` 管理命令及双击聊天入口继续可用。

## 收发消息

在输入开头键入 `/` 会出现命令、参数格式和中文说明，继续输入可过滤。上下键选择，Tab 补全，Esc 关闭；Enter 执行无需参数的命令，需要参数时先补全并等待填写。菜单和 `/help` 使用相同命令列表。

- `/new 标题` 新建对话；对话 ID 为 `t1`、`t2` 等递增短编号。
- `/resume` 按会话名称选择已有对话；方向键选择、Enter 打开、Esc 取消。终端不显示常驻会话侧栏。
- `/approve` 查看当前电脑的待审批命令，选择后可单次同意、拒绝或取消；Esc 仅关闭面板。
- `/title 新标题` 修改标题，ID 不变。
- 输入消息后按 Enter 发送；Alt+Enter 换行，也可粘贴多行文字。
- PageUp / PageDown 滚动记录，`/history` 读取更早的消息。
- `/connect` 显示当前对话的连接 ID、电脑名称和可以复制到 Work 或 Dot 的连接步骤，不会创建新 ID 或改变模型连接。
- `/timing m1` 按需查看该消息的投递分段耗时；省略消息编号时查看最近一条用户消息。
- `/quit` 或 Ctrl+Q 退出终端。退出不删除历史，也不会断开模型订阅。

在 Work 或 Dot 启用 Computer Bridge 后，发送 `/connect` 展示的指令。模型先调用 `chat.resume` 准备连接，再使用宿主的事件任务订阅 `chat.message`，取得连接凭据后即可通过 `chat.reply` 保存回复。`chat.resume` 返回 `subscribed:false` 只表示通知尚未订阅，不影响保存回复；事件订阅不属于普通模型工具列表。普通 Chat 不支持事件唤醒。

一个对话只能连接一个模型对话；新的模型连接遇到已占用的对话会得到“该对话正在被使用”，不会替换原连接。终端和网页可以同时查看、发送消息。

终端运行期间使用独立实时连接接收变化通知，再按游标同步新消息和投递状态。断线后自动重连并补齐记录，不重复发送消息。切换对话会关闭原来的终端实时连接，模型订阅和电脑端连接不受影响。空闲时不定时读取聊天历史。

每条历史消息显示“已保存”，通知和回复单独显示：等待接收方上线、等待通知、暂不可达、宿主已接收、通知配置异常或已回复。宿主接收事件不能代表模型已读或已执行。通知失败不会改变保存状态。

## 附件

```text
/attach /Users/me/Documents/说明 文档.txt
/attach D:\资料\图片.png
/read a1
/download a1
/download a1 /Users/me/Downloads/另存文件.txt
```

`/attach` 添加待发送附件，可重复添加多个。输入文字后发送，或直接按 Enter 发送附件。`/unattach` 清空待发送列表。文件路径中有空格时直接粘贴完整路径即可，也支持用双引号包住完整路径。

上传和下载按块传输，完成时核对大小与 SHA256。`/read` 显示文本附件前一段，完整内容可通过 `/download` 保存。下载默认保存到当前目录，不覆盖已有文件；可以指定新路径。

网络中断导致消息回执未收到时，`/retry` 使用原请求键确认发送结果，不重复生成同一条消息。

所有聊天记录和附件保存在服务器。账号与设备访问范围沿用管理页设置；聊天不会改变工作区、完全访问或命令审批权限。
