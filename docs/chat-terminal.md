# 终端聊天

安装完成后，新开终端，在任意目录输入 `cs` 或 `closesi` 即可进入 TUI。Mac 和 Windows 使用相同命令，安装器自动配置当前用户的命令路径，无需激活 Python 虚拟环境。

Computer Bridge 的终端聊天与已经注册的本机绑定，通过同一服务器收发消息。它不会启动另一个电脑连接，也不会中断正在运行的命令。

```sh
cs
closesi
```

没有保存的账号登录时直接使用本机注册身份，显示这台电脑的对话，不打开登录网页。输入 `/resume` 打开会话名称列表，用方向键选择、Enter 打开，Esc 取消。

需要访问其他电脑时输入 `/login`，在浏览器登录账户并确认。账户模式可查看所有获授权电脑的对话，使用 `/computers` 选择新建对话所用的电脑；`/resume` 列表同时显示会话名称和电脑名称。重新启动 `cs` 会恢复已登录的账户。输入 `/logout` 清除本机保存的凭据并返回本机模式；`cs --login` 可在启动时登录账号。

账户凭据保存在电脑配置旁的 `device-chat.json`，不保存账号密码。修改密码后需重新 `/login`。没有自动打开浏览器时，可以复制终端中的链接；`--no-browser` 只显示链接。`--config` 可指定已注册电脑的配置文件。

`cs --help` 查看参数，`cs --version` 查看当前版本；`cs --resume t1` 可直接打开已知短 ID。`closesi` 支持完全相同的参数。命令入口使用当前安装版本，更新后无需重新配置。原 `computer-bridge` 管理命令及双击聊天入口继续可用。

## 收发消息

在输入开头键入 `/` 会出现命令、参数格式和中文说明，继续输入或删除文字均会更新提示。上下键选择，Tab 补全，Esc 关闭；Enter 执行无需参数的命令，需要参数时先补全并等待填写。菜单和 `/help` 使用相同命令列表。

所有命令弹窗都在底部显示当前可用按键：

- 选项列表用 ↑/↓ 选择、Home/End 到首尾、PageUp/PageDown 翻页，Enter 确认，Esc 关闭。带说明的弹窗用 Tab/Shift+Tab 在说明和选项间切换；说明区用 ↑/↓ 或 PageUp/PageDown 阅读，Enter 只返回选项，不提交选择，Esc 仍可关闭。
- 工作区表单用 ↑/↓ 切字段，Tab/Shift+Tab 可依次切换全部字段和按钮。多行路径框内 ↑/↓ 按屏幕显示行移动，仅在首末显示行切出；Shift+方向键选择文字，不会切走焦点。名称和主路径按 Enter 到下一项，外部子工作区按 Enter 换行，只有保存按钮才提交。
- 文本框的 ←/→ 保留光标移动；按钮区用 ←/→ 切换、Enter 或空格执行，↑ 返回最后一个字段。Esc 取消表单，不保存。Q/E 保持普通文字输入，不设字母导航快捷键。
- 导出路径框按 Enter 保存路径，或按 ↓、Tab 选择保存/取消按钮；导出进度按 Esc 取消导出，按 Enter 或 ↓ 只聚焦取消按钮，再按 Enter 才执行取消。
- 信息弹窗正文用 ↑/↓ 或 PageUp/PageDown 阅读，Tab/Shift+Tab 切换正文和关闭按钮，Enter/Esc 关闭提示。登录提示的关闭只收起提示，不取消浏览器中的登录流程。

- `/new 标题` 新建对话；对话 ID 为 `t1`、`t2` 等递增短编号。
- `/resume` 按会话名称选择已有对话；第一页即可选择，更多对话按需加载。方向键选择、Enter 打开、Esc 取消。终端不显示常驻会话侧栏。
- `/title 新标题` 修改标题，ID 不变。
- 普通 Chat 输入框按 **Shift+Tab** 循环切换普通、计划和自动。`/plan 请求` 进入计划并发出请求，`/plan off` 返回普通。按 **F6** 领取未指定入口的审批；没有可领时，定位当前对话的待审项。
- `/goal` 查看目标，`/goal 目标` 建立目标；用 `/goal edit 新目标`、`/goal pause`、`/goal resume` 和 `/goal clear` 管理。状态和决定与网页同步。
- `/permissions` 设置所选电脑的完全访问与工具规则；`/workspaces` 管理其工作区及外部子工作区。
- `/delete` 经确认后删除当前会话及服务器附件，终端只提示对话已删除；网关在后台通知 Dot 清理该会话的监听。取消保持原样。
- 输入消息后按 Enter 发送；Shift+Enter 换行，Ctrl+J 为通用换行备用，也可粘贴多行文字。旧换行组合继续兼容。
- 将图片或文件拖入输入框，光标处会出现附件标记。Windows Terminal 的普通和管理员标签页都可直接接收资源管理器拖入的文件。可在标记前后继续写说明；按 Enter 上传实际文件，标记与本机路径不会作为正文发送。支持多个文件、含中文和空格的路径，以及 `file://` 路径。删除标记即可移除待发附件。普通正文和代码中的路径保持原文。
- 在 Finder／资源管理器复制文件，或将截图、图片复制到系统剪贴板后，按 **Ctrl+Y** 在光标处插入附件。普通剪贴板文本仍按原文粘贴。剪贴板图片的临时文件在退出 TUI 时清理。
- 右键在指针旁打开系统菜单：有选中文字时可复制，也可以把剪贴板内容粘贴到输入光标处。Windows 有选区时也可按 **Ctrl+C**。Mac 可用 **F2** 进入终端原生选取，拖选后按 **⌘C**，按 Esc 返回。
- 输入框为空时按上键召回当前会话已加载的用户消息，继续上下键浏览；下键越过最新项恢复空输入。召回只填入输入框，编辑后恢复普通光标移动。
- 普通输入框上下键按屏幕可视行移动；较短行保留目标列，第一行继续向上到全文开头，最后一行继续向下到全文末尾。补全与选择窗口打开时，方向键控制对应菜单。
- 按住 Shift 后，四个方向键都可直接开始选择文字；Shift+上／下沿屏幕可视行扩展选区，包括自动折行，无须先左右选中。反向回到起点会取消空选区。
- 输入框获得焦点时，F4 清空全部输入文字和附件标记，可用撤销恢复；不会删除附件原文件或已发送消息。Mac 的功能键设置可能要求 Fn+F4。Windows 有选区时 Ctrl+C 仍用于复制。
- PageUp / PageDown 滚动记录；接近已加载历史顶部时自动提前读取下一页，持续上翻即可查看更早消息。
- `/math` 按消息摘要选择公式消息；`/math m42` 直接打开该消息的完整数学排版。
- `/connect` 通过插件级通道自动通知 Dot 建立或恢复当前对话的 `chat.message` 订阅；发出命令后不立即弹窗，若 1 分钟后仍未检测到 Dot 生效，再自动弹出提醒并建议手动前往 Dot 处理。
- `/disconnect` 通知 Dot 暂停当前对话的 `chat.message` 订阅（或由 Dot 按自身资源情况取消订阅），同样仅在超过 1 分钟未生效时自动弹出提醒；不中断用户与服务器之间的历史保存和实时收发。
- `/update [stable | beta | alpha]` 从 GitHub 官方仓库检查并更新本机客户端；省略渠道时会弹出正式版 / b测 / a测选择框，确认并完成隔离构建后自动重启进入新版本界面。也可在终端直接运行 `cs update` / `closesi update`（支持 `--stable`、`--beta`、`--alpha`、`--check`、`-y`）。
- `/quit` 或 Ctrl+Q 退出终端。退出不删除历史，也不会断开模型订阅。

在 Work 或 Dot 启用 Computer Bridge 后，首次打开时建立插件级 `chat.channel` 订阅，即可自动响应 `/new`、`/connect`、`/disconnect` 与 `/delete`。模型先调用 `chat.resume` 准备连接，再使用宿主的事件任务订阅 `chat.message`，取得连接凭据后即可通过 `chat.reply` 保存回复；收到 `delete` 时仅永久清理已有绑定订阅，无绑定则忽略。`chat.resume` 返回 `subscribed:false` 只表示通知尚未订阅，不影响保存回复；事件订阅不属于普通模型工具列表。普通 Chat 不支持事件唤醒。

一个对话只能连接一个模型对话；新的模型连接遇到已占用的对话会得到“该对话正在被使用”，不会替换原连接。终端和网页可以同时查看、发送消息。

终端运行期间使用独立实时连接接收变化通知，再按游标同步新消息和投递状态。断线后自动重连并补齐记录，不重复发送消息。切换对话会关闭原来的终端实时连接，模型订阅和电脑端连接不受影响。空闲时不定时读取聊天历史。

每条历史消息显示“已保存”，通知和回复单独显示：等待接收方上线、等待通知、暂不可达、宿主已接收、通知配置异常或已回复。宿主接收事件不能代表模型已读或已执行。通知失败不会改变保存状态。

终端只保留底部状态区，右侧固定显示“聊天ID：t1”；左侧依次显示聊天名、模式、当前电脑延迟与热通知（包括临时操作提示、通道通知与投递进度，以及有待审阅方案或待审批命令时的常驻提醒）。使用 `/status` 可随时弹出详情窗查看连接状态、待审阅方案与待审批命令列表、完整通知诊断与最近异常。`/help`、F1 帮助、`/status` 状态与附件查看均可滚动阅读、Esc 关闭。`/new`、`/connect`、`/disconnect` 先显示投递进度，重试中不显示 HTTP 错误码。1 分钟后未生效才提示手动处理，生效后自动关闭提醒。临时网络断线也会保留前段状态并通过热通知提示。快捷键见 `/help`。

本机 Apple Terminal 使用系统 Shift 状态补充识别 Shift+Enter 和没有携带修饰信息的上下键，不改终端配置。上下键在收到转义序列开头时记录 Shift，避免序列分段或等待按键处理期间松开 Shift 导致选区消失；带明确修饰信息的序列保持原有含义，松开 Shift 后的普通上下键取消选择。SSH、tmux、screen 和其他终端只使用实际传入的按键编码，不读取本机键盘状态；无法区分 Shift+Enter 时使用 Ctrl+J。系统状态补偿无法还原首次读取前就已经释放的修饰键，真实终端的快速按放仍须单独验收。


消息框和输入框没有标题或附件计数，输入框也没有三角箭头前缀。空输入或仅有空白时按 Enter 保持原内容，不发送消息，也不触发终端重绘；输入开头按退格、末尾按 Delete 同样忽略，不触发响铃。

鼠标位于消息区时，每个滚轮事件移动三个屏幕行；Page Up／Page Down 按可见高度翻页，并保留一行重叠。长行折行和超长单行也可逐段浏览。向上翻阅后，新消息不会把画面拉回底部；滚回底部后恢复自动跟随。窗口缩放、读取更早历史和审批详情变化时保留阅读位置，滚动不会改变输入框焦点或草稿。

电脑延迟表示服务端到当前电脑再返回的往返耗时，与模型连接状态分别显示。低于 200 ms 为绿色，200—499 ms 为黄色，500 ms 及以上为红色；超时、未知及恢复中为黄色，离线为灰色。运行期间每 5 秒刷新一次，绘制和按键不会触发测速。

方案和审批在消息流中保留原位。审阅使用底部输入区，结束后还原草稿、光标和附件。方案按 1 或 2 批准；Tab 编辑选填理由，Enter 移到「拒绝并要求修改」，再次按 Enter 提交。Esc 或 Ctrl+C 只离开方案，保留待审状态和理由。

单次沙盒外命令在键盘输入空闲一秒后提示审批。用 y 批准本次、d 拒绝、n 取消；Ctrl+A 查看完整命令，q 或 Ctrl+C 返回原审批。设备工具和 Work Tree 使用简短表单，空格只选中，Enter 或编号提交。操作审批中的 Esc 或 Ctrl+C 会取消当前调用。

终端按 F6 可领取尚未指定入口的同设备审批，或定位本对话已有的待审内容。领取只固定位置，还要在底部作出决定。已处理的审批可以查看详情；决定已保存但尚未送到设备时会单独注明。

## Markdown 与数学公式

用户消息和模型回复支持标题、强调、列表、引用、表格、链接及代码高亮。公式支持 `$…$`、`$$…$$`、`\(...\)`、`\[...\]` 和 AMS 环境。消息保存原文，显示方式不改变历史内容。

终端使用二维字符显示分式、矩阵、上下标及多行公式。不支持的命令和超出宽度的公式保留原文并提供 `/math` 入口，不使用问号替代符号。完整查看在本机使用 MathJax 生成 SVG，包含 AMS、physics、自定义宏及消息内编号引用；通过默认浏览器打开，无需登录、安装 TeX 或请求外部公式服务。预览是本次终端会话的临时文件，退出时清理。

带帽、向量箭头、横线等单字形重音可以与上下标和字体嵌套，例如 `e^{-i\hat Ht/\hbar}`。公式在列表、引用和表格中按实际剩余宽度排版，表格中的分式与矩阵保留二维结构。普通文本折行保持组合字形完整，窗口缩放后只应用当前对话和宽度的渲染结果。

终端复用 MathJax 解析消息内的宏、数学字体、physics 命令、环境、编号和引用，再通过 TeXicode 画布排版。支持粗体希腊字母、`\boldsymbol`／`\bm`、运算符界限、上下方注记、左右张量、`alignedat`、矩阵和数组分隔线、伸缩定界符及跨字符重音；宽字形按终端显示列布局。宏、编号和引用按消息隔离。数学编译在本机后台完成，按原文缓存，缩放只重做布局；编译进程空闲 60 秒回收，退出时释放。

终端原生排版不覆盖所有图形及装饰效果。缺少可靠字符表示时明确保留原文并提示 `/math`，不会将 MathJax 编译成功当成终端正确显示。语法错误与原生能力不足分别提示，原文及历史不变。

网页使用同一版本 MathJax 排版，支持查看和复制单个公式的 LaTeX 原文。消息右上角的按钮可以原位切换整条正文的原文、复制原文，并从允许引用的助手消息直接添加引用。宏与编号按消息隔离；代码和转义美元符号不作为公式处理。

正常回答应直接包含 Markdown 正文和 LaTeX 数学分隔符；整篇放在 `markdown` 代码围栏中会按源码展示。仅在明确需要可复制源码时使用这种写法。普通 Unicode 方程保持文字，不自动猜测转换为数学公式。

## 主题与导出

`/theme` 打开深色、浅色、高对比主题列表。选择后立即生效并保存在本机，下次启动继续使用。用户与 GPT／Dot 抬头使用不同颜色，标题、加粗、代码与公式按语义轻量着色。主题切换不重新获取历史或编译公式。

`/export` 下载当前完整会话及附件。选择 ZIP 保存路径后，程序按分页读取开始导出时已保存的全部消息，在本机下载并校验附件、压缩；服务器不生成额外归档。

解压后，会话文件夹包含 `conversation.md` 和 `attachments/`。Markdown 保留原始正文、LaTeX、角色、时间、消息 ID 和审批记录；附件使用标准相对链接，图片可离线查看。相同附件仅保存一次，同名附件通过附件 ID 区分。导出成功后不自动删除服务器会话。

导出期间可取消；失败或取消不会留下被当作完整结果的 ZIP。成功弹框显示保存位置、消息数和附件数。

## 附件与发送恢复

TUI 保留 `/read a1` 查看收到的文本附件、`/download a1 [保存路径]` 下载原文件并校验；添加附件可拖入输入框，或使用 Ctrl+Y。文件不会覆盖已有同名文件。

回执丢失时程序自动用原请求键确认消息结果，同一对话后续发送按顺序处理，不需要手动重试命令。无待确认消息时不增加轮询。未确认的发送仅保留在本次 TUI 运行期间，不增加磁盘离线待发箱。

聊天记录和已发送附件保存在服务器。TUI 本机身份只可配置本机；账号模式可配置账号获授权的电脑。
