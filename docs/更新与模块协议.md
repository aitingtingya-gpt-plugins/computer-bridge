# Computer Bridge 0.2.5-alpha 更新与模块协议

## 发布与渠道

默认更新来源为 `aitingtingya-gpt-plugins/computer-bridge`，管理员可改为自己的 `owner/repository`。正式渠道排除 GitHub prerelease；测试渠道包含正式和预发布，按语义版本排序。客户端和服务端只安装兼容且较新的核心版本，不自动降级。

每个 Release 提供 `release-manifest.json`，格式版本为 1，包含发布版本、源码提交、协议区间和 artifacts。每项资源包含 id、target、组件 version、file、size、sha256、platform、modules、requires。模块另含 module 和依赖名单；requires 可包含核心版本范围及模块 API 版本。清单资源附在同一 Release，大小与摘要必须一致。分支最新提交不作为更新来源。

构建入口为 `scripts/build_release.py`，正式标签与清单版本一致。安装程序和更新器依据清单下载并校验具体资源。

管理员可更新服务器、配置更新来源和管理服务器模块。普通用户只可查看及更新自己获授权的电脑和电脑模块；共享设备的更新状态由有权管理该设备的账号共同查看。

## 运行和交接

Node 稳定入口为 `build/launcher.mjs`，版本目录、更新任务及 SQLite 均在 DATA_DIR 中。Docker 持久挂载 DATA_DIR，日常更新不访问 Docker socket。电脑稳定入口为安装目录中的 `launcher.py`，`active.json` 指向当前独立环境。业务进程不替换自身文件。

更新依次下载资源、核验摘要、准备独立目录、等待目标空闲、切换并核验通信。更新任务保留编号，刷新页面或再次点击沿用未结束任务。切换前可取消。设备身份、账号授权、会话、短编号、请求回执、工作区、代理和锁屏设置继续保留；失败时恢复程序版本，业务数据留在原位置。

核心、模块和通信协议各自有版本。握手包含 protocol、capabilities、module_versions，功能按双方支持的能力开放。没有更新执行器的电脑需运行安装程序接入更新功能。模块 API 当前为 1。

## 模块

电脑模块通过 Python entry point `computer_bridge.modules` 注册。模块类提供 api_version、requirements、tools、call、event、accepts_context、validate_context、command_result、busy、close 和 configure。安装与启用是独立状态；模块忙时不切换。依赖缺失、版本不兼容和未启用分别呈现。

Node 服务模块是独立 ESM 包，默认导出 GatewayModule，包含版本、core 范围、编号规则、文件归属与确认说明。服务器模块和电脑模块独立安装、启用及卸载。Cloudflare 使用基础版及带模块的预构建 Worker，通过同一更新流程切换。

Work Tree 电脑连接模块要求兼容的 Work Tree 本体，当前范围为 `>=0.1.6,<0.2`。本体不在基础包或本仓库中。安装可从已有本体的 direct_url 元信息取得原来源，也可显式传入 `--dependency-source work-tree=安装来源`；连接模块不自行选择或升级本体版本。卸载连接模块保留原科研文件和业务历史。

首次使用指定本体来源时，将其固定为该电脑上的安装资源。后续核心更新复用该资源，不跟随原源码目录或下载地址的变化自动更新本体。

## Cloudflare 更新执行器

先部署业务 Worker；再按 `wrangler.updater.example.jsonc` 部署独立更新 Worker，将 TARGET 服务绑定指向业务 Worker 的 Maintenance；最后为业务 Worker 添加 UPDATER 服务绑定，指向更新 Worker。两个 Worker 使用不同脚本名，更新 Worker 不公开公网入口。

更新 Worker 配置 CF_ACCOUNT_ID、CF_WORKER_NAME、TARGET_URL，并以 secret 设置 CF_API_TOKEN。令牌用于读取设置、上传 Worker 版本和切换部署，由部署者配置。更新保留已有域名、绑定、认证及存储；未安装更新 Worker 时管理页继续工作，服务器更新不可用。

执行器等待在途请求完成，再以 immediate 策略切换 Durable Object 的代码，并核验公开入口、业务对象和实际部署版本。启动验证失败时恢复上一程序版本，确认通信恢复后更新任务结果。取消与阶段推进使用同一持久任务记录。

若更新来源是私有 GitHub 仓库，需配置 `GITHUB_RELEASE_TOKEN`；公开仓库无需该凭据。Node 从环境读取，Cloudflare 分别为业务 Worker 和更新 Worker 设置 secret。
