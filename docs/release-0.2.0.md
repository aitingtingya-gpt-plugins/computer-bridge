# Computer Bridge 0.2.0

Computer Bridge 的首个公开版本，通过标准 MCP 和 OAuth，让 GPT／Dot 操作自己部署的服务中已注册电脑的文件与终端。

- 支持 macOS、Windows 电脑端，服务端可部署为 Node.js、Docker 或 Cloudflare Worker。
- 管理员创建普通账号并分配设备授权；一台设备可供多个用户管理，设备和账号均使用稳定短 ID。
- 文件工具支持目录浏览、搜索、文本及二进制读写、精确替换、补丁、移动、删除、图片查看和登录后下载。
- 命令支持 UTF-8 输入输出、直接返回短输出、长结果分页、等待、停止及结果回收。
- 工作区写入限制复用 DSH 沙盒核心，可配置外部子工作区；完全访问按本机当前用户权限运行。受限模式下可单次批准命令在沙盒外运行。
- 网络中断后可按原请求号恢复结果，已执行的操作不会因恢复而重放。
- 默认锁屏模式阻止自动空闲睡眠，管理页提供连接状态和手动延迟检测。
- 支持 `.work` 技能与智能体定义，附带 DSH、Codex 适配脚本；Work Tree 连接模块可独立选装。
- 管理页可检查 GitHub Release，并更新中转服务和获授权的在线电脑。

`computer-bridge-0.2.0-install.zip` 包含服务端、Windows、Mac 三部分源码安装入口。独立核心、更新执行器和可选模块资源附在同一 Release，资源版本、源码提交及 SHA256 见 `release-manifest.json` 和 `SHA256SUMS`。

安装步骤见仓库的源码安装说明；接入地址和部署配置由部署者自行设置。
